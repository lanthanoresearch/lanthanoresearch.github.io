Add to Home Screen

Apple does not allow apps to be installed from a website, so on iPhone and iPad the site is added to your Home Screen instead. It opens like an app.

  1. Open this site in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.

Install the app

Install turns the whole website into a real app, with every paper, image and video inside it, so it works without internet. The app is installed on your device like any other app.
